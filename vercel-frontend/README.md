# إدارة البرج — نشر مستقل على Vercel

هذا المجلد أصبح نسخة مستقلة كاملة، تشمل الواجهة وواجهات API. لم يعد يحتاج إلى خادم Backend خارجي أو رابط تجريبي.

## إعدادات Vercel

- **Root Directory:** `vercel-frontend` إذا اخترت هذا المجلد كجذر، أو `./` إذا اخترت جذر المستودع الأساسي.
- **Framework Preset:** Other
- **Build Command:** `npm run build`
- **Output Directory:** `dist`
- **Install Command:** `npm install`

أضف متغيرات البيئة المطلوبة كما هو موضح في `../README.md`، خصوصًا متغيرات PostgreSQL وDiscord و`SESSION_SECRET` و`SITE_URL` و`DISCORD_REDIRECT_URI`. يجب أن يكون `SITE_URL` هو رابط الموقع المنشور نفسه، ويجب إضافة رابط `/auth/callback` إلى Discord Developer Portal.

بعد الحفظ، أعد النشر من Vercel. لن تعمل عمليات المهمات أو الشات ما لم تنشر مجلدًا يحتوي على `api/` بجانب `package.json` و`vercel.json`.

The project includes explicit API wrappers for nested task, chat, submission-review, staff-request-review, and staff-profile routes. Ensure this folder is deployed with its `api/` directory intact; deploying only `site-src/` or the generated `dist/` folder will cause API requests to return Vercel `NOT_FOUND` errors.


## إحصائيات الإدارة والطلبات الإدارية
تعرض الصفحة الرئيسية ملخصات المسؤولين، والضغط على اسم عضو من القائمة الجانبية يفتح ملفه الكامل. يستطيع عضو الاستاف إرسال طلب إجازة أو طلب إداري آخر (إذن/غياب، مشكلة تقنية، تعديل بيانات، شكوى/ملاحظة، أو طلب آخر). تصل طلبات الإجازة ومراجعاتها إلى الروم `1556945732957765722`، بينما تصل جميع الطلبات الإدارية الأخرى (الإذن/الغياب، المشكلة التقنية، تعديل البيانات، الشكوى، والطلبات الأخرى) وكذلك إشعارات قبولها ورفضها إلى الروم `1560142058826768425`. معرّف روم الطلبات الإدارية مثبت في الكود، ولا يغيّر مسار الإجازات. يمكن لمسؤولي الإدارة قبول الطلبات أو رفضها من لوحة الموقع. الموافقة على طلب عادي لا تغيّر رتب Discord؛ الرتبتان المعرّفتان في إعدادات الموقع تُستخدمان لتحديد صلاحيات الإدارة فقط.

ملاحظة: روم طلبات الإجازة ومراجعتها مثبت على `1556945732957765722` في الكود حتى لا تغيّره قيمة بيئة قديمة بالخطأ؛ بعد تحديث الملفات أعد النشر على Vercel. لا تحتاج إلى ضبط `LEAVE_REQUEST_CHANNEL_ID`.


## مراجعة طلبات الإجازة من الموقع وديسكورد
- كل طلب إجازة جديد ينشر في الروم `1556945732957765722` مع زري **قبول الإجازة** و**رفض الإجازة**.
- القرار من الموقع أو ديسكورد يتسجل في قاعدة البيانات نفسها ويحدّث رسالة الطلب الأصلية مع إزالة الأزرار بعد المراجعة.
- أضف متغير `DISCORD_PUBLIC_KEY` إلى Vercel من **General Information → Public Key** في Discord Developer Portal.
- اضبط **Interactions Endpoint URL** إلى `https://رابط-موقعك/api/discord-interactions` بالدومين الفعلي المنشور، ثم أعد النشر.
- بعد النشر سجّل الخروج من الموقع ثم ادخل مرة أخرى لتحديث صلاحيات رتب الإدارة. لازم يكون متغير `DISCORD_BOT_TOKEN` مضبوطًا، والبوت عنده صلاحية عرض وإرسال الرسائل وتعديل رسائله في روم الإجازات.
